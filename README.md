# Lok Sabha Election Data Analysis (2004–2024)

## Project Overview

This project analyses Indian Lok Sabha election data from 2004 to 2024 using Python and statistical techniques. It explores voting patterns, voter turnout, political party performance, and election results across states and election years.

The project uses exploratory data analysis, descriptive statistics, data visualization, and hypothesis testing to identify trends and relationships in election data.

## Objectives

- Analyse voter turnout across different states and election years.
- Study political party performance using votes and seats won.
- Examine winning margins and differences in electoral outcomes.
- Explore relationships between the number of electors and voter turnout.
- Apply statistical tests to investigate differences and relationships in election data.

## Project Files

| File | Description |
|---|---|
| `LokSabha_Data_Analysis.ipynb` | Exploratory data analysis, descriptive statistics, and visualizations of election trends. |

## Tools & Technologies

- **Programming:** Python
- **Data manipulation:** Pandas, NumPy
- **Statistical analysis:** SciPy, Statsmodels
- **Data visualization:** Matplotlib, Seaborn
- **Statistical methods:** Descriptive statistics, correlation, hypothesis testing, t-test, ANOVA, and regression analysis

## Analysis Performed

### 1. Exploratory Data Analysis

- Analysed state-wise and year-wise voter turnout.
- Examined political party performance across election years.
- Identified constituencies with high and low winning margins.
- Explored relationships between electorate size and voter turnout.
- Created charts and graphs to communicate electoral trends.

### 2. Statistical Hypothesis Testing

- Compared voter turnout across selected election years.
- Examined differences in winning margins.
- Compared selected party and state-level election outcomes.
- Investigated relationships between electorate size and voter turnout.
- Used statistical tests to assess evidence for differences and associations.

*Note: Statistical results should be interpreted in the context of the data, test assumptions, and limitations. Observational comparisons do not establish causation.*

1. Clone or download this repository.
2. Install the required libraries:


3. Open the notebooks in Jupyter Notebook or Google Colab.
4. Download or place the required election dataset in the appropriate folder.
5. Update the dataset paths in the notebooks, if necessary.
6. Run the notebook cells in order.
